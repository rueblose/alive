# Nebula — библиотека Ableton как облако точек

Каждый проект — одна светящаяся точка. Шесть её свойств несут шесть величин сета
одновременно: три координаты, размер, плотность и цвет.

Это отдельная программа на основе **Alive**: оформление (`Theme`, `Glass`, `Controls`,
`Icons`, диалог папок `RootsDialog`) и весь разбор данных (`AlsFile`, `ProjectIndex`,
`PluginInventory`, …) берутся исходниками из `..\src` — не копией, а теми же файлами.
Своего в Nebula только три: каналы (с чекбоксами и иконками камеры), облако и окно.

## Что во что подставлено

По умолчанию:

| Канал | Величина | Почему |
|---|---|---|
| **X** | Tracks | сколько дорожек — грубая мера «насколько большой замес» |
| **Y** | Plugins | сколько разных плагинов в сете |
| **Z** | BPM | темп: настоящая музыкальная ось, есть у каждого сета и хорошо разбросана |
| **Размер** | Project size | вес всей папки проекта — сэмплы, рендеры, всё |
| **Плотность** | Created | старые тают, свежие горят — видно, что придумано недавно, а что лежит с основания проекта |
| **Цвет** | Live version | какой версией Live сохранён сет — миграция библиотеки видна как течение цвета |

Камера при запуске стоит на виде **XY** (см. «Камера» ниже) — плоско на X/Y, без
вращения, автоспин выключен: первый взгляд на облако должен быть читаемым графиком,
а не случайным ракурсом.

Любой канал переключается на любую из шестнадцати величин: Tracks, Plugins, BPM, Key,
Scale, Project size, Set file size, Sample refs, Missing files, Missing plugins, Modified,
Created, Live version, Collection, Name A→Z и Scatter (случай — рассыпать по оси, когда
она не нужна).

Правило одно и то же во всех каналах: **больше значение — дальше, крупнее, ярче**. Поэтому
«Fade · Missing files» гасит всё здоровое и оставляет светиться только сломанные проекты, а
«Fade · Modified» — наоборот, показывает, чем занимались в последние месяцы.

Рядом с каждым каналом — чекбокс: выключает канал, не забывая выбор в списке. Выключенная
ось X/Y/Z схлопывает облако вдоль неё (получается честная проекция на оставшиеся два
измерения), выключенный Size/Fade даёт всем точкам одинаковый размер и яркость, выключенный
Colour красит все точки одним нейтральным тоном.

Выбор и состояние галочек запоминаются в `%APPDATA%\Alive\nebula.cfg`.

## Камера

Четыре иконки-кубика рядом с «Reset view» — это не переключатель с постоянным
состоянием, а мгновенное действие:

* **свободный угол** (нейтральный кубик, все грани ровные) — вид по умолчанию, обычная
  перспектива;
* **Front / Side / Top** (кубик с одной светящейся гранью — той, что смотрит на камеру)
  — три ортографических вида на куб, без перспективного схождения: как в CAD, размер
  точки при этом не зависит от глубины.

Клик по любому из них выключает автовращение (иначе кадр, только что вставший по оси,
через секунду снова скосился бы) и сбрасывает зум/панораму. После этого можно тянуть
мышью и крутить дальше — иконка просто перестаёт быть «правдой» для текущего вида, она
не отслеживает состояние постоянно. Тот же вид XY — это ещё и то, что стоит при первом
запуске, и то, куда возвращает `R` / «Reset view».

Мышь вращает инвертированно: тащишь сцену, а не дёргаешь камеру за поводок — тянешь
вправо, и объект под курсором доворачивается влево, как будто он и правда у тебя в руке.

## Размытие, прозрачность и размер точек

Пять ползунков под списком каналов:

* **BLUR** — насколько мягкий край у точки: от почти сплошного диска с тонкой
  сглаженной кромкой (0) до мягкого свечения на весь радиус (1, старое поведение по
  умолчанию). По умолчанию 0.42, ближе к чёткому краю — у плотного облака сплошные
  диски проще отличить друг от друга, чем перекрывающиеся ореолы.
* **MIN FADE / MAX FADE** — альфа (0–100%) у точки с наименьшим и с наибольшим значением
  канала Fade, то есть куда именно ложится шкала 0..1 этого канала. По умолчанию 16–100%:
  самый тусклый конец шкалы не гасится в ноль, иначе такие точки тонут в фоне и их
  как будто вообще нет.
* **MIN SIZE / MAX SIZE** — радиус (в px) у точки с наименьшим и с наибольшим значением
  канала Size, то есть куда именно ложится шкала 0..1 этого канала. Полезно, когда
  канал Size выключен галочкой (тогда все точки берут MIN SIZE) или когда разброс
  величины слишком мал, чтобы читаться в стандартном диапазоне 2–16 px.

Оба диапазона можно перевернуть (поставить Min выше Max) — получится инверсия: то, что
должно быть крупным/ярким, станет мелким/тусклым, и наоборот. Не баг, а способ проверить
гипотезу «а что если наоборот» одним движением ползунка.

## Палитра

Когда в Colour стоит непрерывная величина (BPM, размер, дата, версия — что угодно, кроме
Key/Scale/Collection, у них своя раскраска по классам), под каналами появляется список
**Palette** — Nebula, Viridis, Plasma, Inferno, Ocean. Смешивает цвета внутри каждого
градиента не GDI+ напрямую по RGB, а через **CIELAB**: у прямого RGB-перегона между двумя
насыщенными, но разными по светлоте цветами середина обычно проседает в грязно-серое —
глаз видит готовую примесь. В LAB светлота и цветность разъединены, и середина остаётся
чистым цветом. Легенда справа рисуется тем же Sample(), которым красятся сами точки —
она не может разойтись с тем, что видно на облаке.

## Что как считается

* **Шкалы** режутся по 2-му и 98-му процентилю: один проект на 40 ГБ иначе сплющивает
  остальные в точку у нуля. У размеров и числа ссылок шкала логарифмическая.
* **Нет данных — не ноль.** У сетов из Live 10 нет общей тональности, у части нет темпа;
  такие точки уходят в центр оси и красятся серым, а не притворяются нулём.
* **Вес папок** в кеше Alive не лежит намеренно (записал сэмпл — папка потяжелела, а `.als`
  не изменился), поэтому Nebula считает его сама в фоне: облако видно сразу, точки просто
  раздуются, когда числа приедут.

## Данные

Каталог берётся из кеша Alive (`%APPDATA%\Alive\index.cache`) — если Alive уже сканировала
библиотеку, Nebula открывается мгновенно. Кнопка ⟳ пересканирует те же корни, кнопка с
папкой открывает тот же диалог папок, что и в Alive (список корней со счётчиком сетов,
drag-and-drop, системный проводник Windows). Обе программы читают и пишут одни и те же
настройки, включая список папок.

## Управление

| | |
|---|---|
| тянуть мышью | вращать |
| колесо | зум |
| правой кнопкой тянуть | двигать сцену |
| навести | прочитать точку |
| щёлкнуть | закрепить в карточке |
| двойной щелчок | открыть папку проекта в проводнике |
| `Space` | вращение само по себе |
| `R` | вернуть камеру к виду XY |
| `F5` | пересканировать |
| `Esc` | снять выбор |

## Сборка

```cmd
build.cmd
```

Готовый файл — `nebula\bin\Nebula.exe`. Как и Alive: компилятор из состава
.NET Framework 4.x, ставить нечего, зависимостей рядом с exe нет.
