# Alive b1.3 — Ableton Live Project & Plugin Manager

**Alive** — быстрый, красивый и портативный менеджер проектов и плагинов для **Ableton Live**
под Windows. Автономный exe, без установки и внешних DLL. Интерфейс на английском.

---

## Две сборки

`build.cmd` собирает обе. Alive — это каталог; AliveReel — тот же каталог плюс два окна,
которые прицеплены снаружи и в основной сборке не появляются.

| | `Alive.exe` | `AliveReel.exe` |
|---|:---:|:---:|
| Каталог сетов, плагины, восстановление, плеер, настройки | ✅ | ✅ |
| **Forks** — версии сета со снимками и семантическим diff (`Ctrl H`) | — | ✅ |
| **Stat** — вся библиотека одним облаком точек | — | ✅ |

Внутри `src/` ничего ради Reel не менялось: кнопка **Forks** появляется в инспекторе только
если на событие `DetailPanel.ForksRequested` кто-то подписался, а подписывается
[proto/AliveReelProgram.cs](proto/AliveReelProgram.cs). Подробности — в
[proto/README.md](proto/README.md).

## Возможности

### Каталог

- **Индексация сетов.** Потоковый разбор `.als` (gzip поверх XML) — BPM, тональность, версия
  Live, число треков, дата создания, вес всей папки проекта, список плагинов и ссылок на файлы.
- **Главная (плитками).** `Tab` переключает список и плитки. На плитках — превью аранжировки,
  дата, кнопка Play, если рядом нашёлся рендер. Секции **Pinned** (закреплённые) и **Recent**;
  первая плитка в Recent создаёт новый проект.
- **Схлопывание версий.** У проекта обычно десяток `.als` (`v1`, `final`, `final 2`) — в одну
  строку сворачивается вся папка, хвостик со счётчиком раскрывает конкретные сеты.
- **Фильтры и поиск.** `F` — фильтры по дате, версии Live, ноте и ладу, числу треков и
  плагинов, состоянию файлов и наличию рендеров. `Ctrl F` — поиск по имени. Колонки таблицы
  настраиваются: состав, порядок, ширины.
- **Теги и заметки.** `Ctrl T` — свои метки и текст к проекту. Привязаны к папке проекта, а не
  к `.als`, поэтому не теряются, когда рядом появляется `final 2.als`.
- **Слежение за папками.** Новый сет появляется в каталоге сам, без `F5`.
- **Случайный сет.** Кнопка с костью выделяет наугад один сет из тех, что сейчас видны, —
  с учётом фильтров и поиска.

### Плагины

- Отдельная вкладка (`Ctrl 2`) со всеми плагинами библиотеки: где стоит, чем является, в
  скольких сетах используется, установлен ли сейчас.
- Состав берётся из **базы самой Live**, причём сразу из всех установленных версий: плагины
  стоят в системе, а каждая установка Live — лишь снимок того, что она успела просканировать.
  В настройках можно выбрать конкретную установку или переключиться на обход папок VST2/VST3.

### Восстановление

**Rescue** (`Ctrl R`) — сет не открывается? Alive читает журнал самой Live и называет плагин,
на котором она умерла (`VST3: Going to restore: X` — последняя строка перед смертью), а если
журнал молчит — ищет виновника пробами на копии.

Оригинал не меняется никогда: в **копии** сета подменяется только идентификатор плагина
(`Uid`/`UniqueId`), Live показывает его как «плагин не найден», а всё остальное — узлы,
цепочки, автоматизация, блоб пресета — остаётся байт в байт.

**Collect All** — соседняя кнопка того же инспектора: собрать все медиафайлы сета (свои,
из чужих проектов, из User Library, из факторных паков — как в «Collect All and Save»
самой Live, с теми же четырьмя галочками) в отдельную переносимую папку рядом с проектом.
Перед копированием показывает число файлов и вес по каждой категории — паки часто тянут
несколько гигабайт, и это стоит видеть до нажатия, а не после.

Оригинал не меняется никогда: копируется только сама папка, а в её `.als` пути к
скопированным файлам переписаны на новое место. Не нашедшийся или не скопировавшийся
сэмпл не портит ссылку — она остаётся как в оригинале, а число потерь идёт в уведомление.

### Звук и вид

- **Плеер рендеров.** `Space` — послушать рендер рядом с сетом. `Samples`, `Backup` и
  служебные папки Live отброшены, порядок — по правдоподобности: `Render`/`Bounce`, потом
  корень проекта. Любой файл можно закрепить главным превью.
- **Превью аранжировки.** `Ctrl Space` — картинка сета целиком, в цветах самой Live.
- **Glassmorphism UI.** Векторный интерфейс, всё рисуется в коде и масштабируется под DPI.
  Горизонтальная прокрутка таблицы — `Shift`+колесо, колонка имени остаётся на месте.

### Настройки и Options.txt

Клик по названию программы в шапке. Плавная прокрутка, отключение прозрачности (на Windows 10
акрил пересчитывается на каждый сдвиг окна и оно едет за курсором с задержкой), источник списка
плагинов — и редактор скрытых опций самой Live: **153 опции** с описанием и пометкой
надёжности, галочкой вместо правки текстового файла, с резервной копией перед записью.
Подробности — в [docs/options-txt.md](docs/options-txt.md).

## Горячие клавиши

| | | | |
|---|---|---|---|
| `F1` | Справка | `Enter` | Открыть сет в Live |
| `Tab` | Плитки ⇄ список | `Shift Enter` | Показать в проводнике |
| `Ctrl 1` / `Ctrl 2` | Сеты / Плагины | `Space` | Слушать рендер |
| `F` | Фильтры | `Ctrl Space` | Превью аранжировки |
| `Shift F` | Папки для сканирования | `Ctrl T` | Теги и заметки |
| `Ctrl F` | Поиск | `Ctrl R` | Восстановить сет |
| `F11` / `Ctrl M` | Полный экран / свернуть | `F5` | Пересканировать |
| `Ctrl Q` | Выход | `Ctrl N` | Запустить Live |

В `AliveReel.exe` добавляется `Ctrl H` — версии выделенного сета.

## Загрузка

Готовый архив — в разделе [Releases](../../releases).

1. Распакуйте архив.
2. Запустите `Alive.exe` (или `AliveReel.exe`, если нужны Forks и Stat).
3. Укажите папки с проектами Ableton Live и нажмите **Scan**.

## Сборка из исходников

Тяжёлых IDE не нужно — используется компилятор `.NET Framework 4.x`, входящий в состав Windows.

```cmd
build.cmd
```

Появятся `bin\Alive.exe` и `bin\AliveReel.exe`. Второй собирается и отдельно —
`proto\build-proto.cmd`.

## Не запускается / не видит плагины

1. **«Windows защитила ваш компьютер»** — приложение без цифровой подписи, SmartScreen ругается
   на все такие. Нажмите **Подробнее → Выполнить в любом случае**.
2. **Файл скачан или пришёл в мессенджере** — правой кнопкой по `Alive.exe` → **Свойства** →
   галочка **Разблокировать** → OK. Без неё Windows может закрыть программу молча.
3. **Антивирус удалил файл** — добавьте папку с `Alive.exe` в исключения.
4. **Пустой или неполный список плагинов** — нужно хотя бы раз запустить Ableton Live: список
   берётся из её базы, а не из папок VST. Если он всё равно пуст, откройте
   **Live → Preferences → Plug-Ins → Rescan**. В настройках можно выбрать конкретную установку
   Live или переключиться на обход папок VST2/VST3 своими силами.
5. **Что-то не так** — программа пишет журнал последнего запуска в `%APPDATA%\Alive\alive.log`:
   там версия Windows, версия .NET, где нашлась Live и что именно не удалось. Этот файл —
   первое, что стоит прислать.

Требуется **.NET Framework 4.6+** — он есть в Windows 10 и 11 из коробки.
