# Alive b1.3 — Ableton Live Project & Plugin Manager

**Alive** — быстрый, красивый и портативный менеджер проектов и плагинов для **Ableton Live** под Windows.

![Interface Preview](https://raw.githubusercontent.com/username/repository/main/preview.png)

---

## ✨ Ключевые возможности

- 🎵 **Мгновенная индексация проектов**: Сканирование `.als` сетов, отображение BPM, ключа (Key), времени создания и используемых плагинов.
- 🎛 **Управление плагинами**: Отслеживание установленных и отсутствующих VST/AU инструментов в ваших сетах.
- 🚑 **Восстановление проектов**: Сет не открывается? Alive читает журнал самой Live и называет
  плагин, на котором она умерла, а если журнал молчит — ищет виновника пробами на копии сета.
  Оригинал не меняется никогда.
- 🎚 **Аудио-плеер и предпрослушивание**: Прослушивание рендеров сетов прямо в интерфейсе программы.
- 🕓 **Версии проекта (Forks)**: Снимки сета с сообщением «что я тут сделал», разница между
  версиями по смыслу, а не по тексту, и откат. Хранятся в `Backup\Alive` внутри самой
  папки проекта, рядом с бэкапами самой Live.
- 🌌 **Stat**: Вся библиотека одним облаком точек — шесть свойств точки несут шесть величин
  сета сразу (треки, плагины, BPM, размер, дата, версия Live).
- ⚙️ **Настройки и Options.txt**: Клик по названию программы в шапке. Там же режим
  совместимости с Windows 10, выбор источника списка плагинов и редактор скрытых опций
  самой Live — 153 опции с описанием, галочкой вместо правки текстового файла.
- 🎨 **Современный Glassmorphism UI**: Адаптивный векторный интерфейс с поддержкой ретина-масштабирования.
- 🚀 **100% Portable**: Одно приложение `Alive.exe` без установочных файлов и внешних DLL.

## 📥 Загрузка (Download)

Скачайте готовый архив с программой из раздела **[Releases](../../releases/tag/vb1.3)**.

1. Распакуйте архив `Alive_b1.3.zip`.
2. Запустите `Alive.exe`.
3. Укажите папки с вашими проектами Ableton Live и нажмите **Сканировать**.

## 🛠 Сборка из исходников (Building from Source)

Для сборки приложения не требуется установка каких-либо тяжелых IDE (Visual Studio) — используется штатный компилятор `.NET Framework 4.x`, входящий в состав Windows.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/alive.git
   cd alive
   ```
2. Запустите скрипт сборки:
   ```cmd
   build.cmd
   ```
3. Готовый файл появится в папке `bin/Alive.exe`.

## ❓ Не запускается / не видит плагины

1. **«Windows защитила ваш компьютер»** — приложение без цифровой подписи, SmartScreen ругается на все такие. Нажмите **Подробнее → Выполнить в любом случае**.
2. **Файл скачан или пришёл в мессенджере** — правой кнопкой по `Alive.exe` → **Свойства** → галочка **Разблокировать** → OK. Без неё Windows может закрыть программу молча.
3. **Антивирус удалил файл** — добавьте папку с `Alive.exe` в исключения.
4. **Пустой или неполный список плагинов** — состав берётся из базы самой Live, а не из папок VST,
   и сразу из всех установленных версий Live: плагины стоят в системе, а каждая установка Live —
   лишь её снимок того, что она успела просканировать. Нужно хотя бы раз запустить Ableton Live;
   если список всё равно пуст, откройте **Live → Preferences → Plug-Ins → Rescan**. В настройках
   (клик по названию программы) можно выбрать конкретную установку Live или переключиться на
   обход папок VST2/VST3 своими силами.
5. **Что-то не так** — программа пишет журнал последнего запуска в `%APPDATA%\Alive\alive.log`: там версия Windows, версия .NET, где нашлась Live и что именно не удалось. Этот файл — первое, что стоит прислать.

Требуется **.NET Framework 4.6+** — он есть в Windows 10 и 11 из коробки.
