# Alive

**Быстрый портативный каталог проектов, плагинов и сэмплов Ableton Live.**

Один `.exe`. Без установки, без внешних DLL, без рантайма.

## Зачем

За несколько лет в Live набираются сотни `.als` в десятках папок, и у каждого проекта своя стопка
бэкапов. Проводник показывает только имена и даты. Alive открывает сами сеты и показывает, что
внутри: темп, тональность, плагины, сэмплы и какая версия последняя.

Интерфейс программы на английском, эта страница — перевод основной.

## Возможности

### Главная

Каждый проект — плитка с картинкой его аранжировки, так что трек узнаётся по форме раньше, чем по
названию. Звёздочка держит проект в начале, кнопка play включает рендер, который лежит рядом с сетом.

Над плитками — год работы в Live: активные дни, текущая серия и рекорд, час, когда обычно
начинается работа, и сколько весит вся библиотека.

### Сеты

<img src="docs/img/sets.png" alt="Список сетов и панель проекта">

- **Всё о сете сразу:** темп, тональность, версия Live, треки, плагины, файлы и вес всей папки
  проекта.
- **Одна строка на проект.** `v1`, `final` и `final 2` сворачиваются в одну строку, счётчик в конце
  её раскрывает.
- **Фильтры** (`F`): дата, версия Live, тональность, число треков и плагинов, пропавшие файлы,
  рендеры. **Поиск** — `Ctrl F`. Колонки можно выбрать.
- **Теги и заметки** (`Ctrl T`). Они привязаны к папке проекта, поэтому не теряются, когда рядом
  появляется `final 3.als`.
- Новые сеты появляются сами, пересканировать не нужно.

<img src="docs/img/filters.png" alt="Фильтры" width="560">

### Плагины

<img src="docs/img/plugins.png" alt="Библиотека плагинов">

Все плагины одним списком (`Ctrl 3`): кто сделал, в скольких сетах стоит и установлен ли ещё. Список
берётся из базы плагинов самой Live или, если так удобнее, из папок VST2/VST3.

### Сэмплы

<img src="docs/img/samples.png" alt="Библиотека сэмплов: дерево папок и использование одного пака">

Какие паки реально идут в дело, а какие скачаны и ни разу не тронуты (`Ctrl 4`). Папки можно
добавить самому или взять те, что уже знает Live.

- Использование считается **по проектам**: десять версий одного трека — одно использование.
- **Never used** — самые большие папки, из которых не взято ни одного звука.
- **Most used** — звуки, которые идут в ход постоянно.
- **Duplicates** — один и тот же файл в нескольких местах, самые большие потери места первыми.
- Клик по сэмплу — и он играет, как в браузере Live. Его можно перетащить прямо в Live.
- Панель сета на вкладке Sets показывает, из каких папок он берёт сэмплы; клик открывает папку здесь.

<img src="docs/img/samples-never.png" alt="Never used: самые тяжёлые папки, из которых ничего не взято">

Alive не перемещает и не удаляет сэмплы: это сломало бы все сеты, где они звучат. Программа
показывает, что можно убрать, а убирать — уже в проводнике.

### Восстановление

<img src="docs/img/rescue.png" alt="Восстановление — сет проверяется плагин за плагином" width="560">

Сет не открывается? Alive читает журнал Live и называет плагин, на котором она упала. Если журнал
молчит, Alive ищет виновника сам: отключает плагины в копии сета, пока та не откроется. Оригинал не
трогается.

### Export

<img src="docs/img/export.png" alt="Диалог экспорта" width="560">

Всё, что нужно сету (свои сэмплы, файлы из других проектов, User Library, паки), собирается в одну
папку или `.zip` — как *Collect All and Save* в Live. Ещё до начала видно, сколько файлов и гигабайт
добавит каждая группа. Оригинальный сет не меняется.

### Превью и плеер

<img src="docs/img/preview.png" alt="Превью аранжировки">

`Ctrl Space` показывает всю аранжировку одной картинкой, в цветах клипов Live. `Space` включает
рендер, который лежит рядом с сетом; главный файл можно выбрать.

### Stat

<img src="docs/img/stat.png" alt="Stat — библиотека одним облаком точек">

Вся библиотека облаком точек, по точке на проект. Что показывают оси, размер и цвет точки, выбираете
вы: темп, число треков, год и так далее.

### Настройки

<img src="docs/img/settings.png" alt="Настройки" width="560">

`Ctrl ,` или шестерёнка: плавная прокрутка, прозрачность и проверка обновлений (все три после
установки выключены), а ещё откуда брать список плагинов.

**Обновления.** В сеть Alive ходит, только когда вы просите: кнопкой **Check for updates** или
ежедневной проверкой — тогда о новой версии скажет точка на шестерёнке. Ничего о вас и вашей
библиотеке не отправляется.

Там же ссылки на этот репозиторий и телеграм-канал разработчика,
[t.me/RueBlose](https://t.me/RueBlose), и кнопка, открывающая [папку данных](#папка-данных).

## Загрузка

Готовый архив — в [Releases](../../releases).

1. Распакуйте архив.
2. Запустите `Alive.exe`.
3. Укажите папки с проектами Ableton Live и нажмите **Scan**.

Нужен **.NET Framework 4.6+** — он уже есть в Windows 10 и 11.

| | | | |
|---|---|---|---|
| `F1` | Справка | `Enter` | Открыть сет в Live |

| `Ctrl Q` | Выход | `F5` | Пересканировать |
| | | `Ctrl N` | Запустить Live |

## Если что-то не так

1. **«Windows защитила ваш компьютер».** У программы нет цифровой подписи, поэтому SmartScreen
   предупреждает. Нажмите **Подробнее → Выполнить в любом случае**.
2. **Ругается антивирус.** Alive копирует файлы и пишет архивы, и некоторым антивирусам это кажется
   подозрительным. Это ложное срабатывание: весь код лежит здесь и собирается одной командой.
   Добавьте папку в исключения.
3. **Сразу закрывается.** Если файл скачан или пришёл в мессенджере: правой кнопкой по `Alive.exe` →
   **Свойства** → галочка **Разблокировать** → OK.
4. **Нет плагинов или не все.** Live должна была запуститься хотя бы раз: список берётся из её базы.
   Всё равно пусто — в Live **Preferences → Plug-Ins → Rescan** или в настройках Alive переключитесь
   на папки VST.
5. **Что-то другое.** Пришлите `%APPDATA%\Alive\alive.log`: там написано, что происходило при
   последнем запуске.

## Папка данных

Всё, что Alive помнит, лежит в `%APPDATA%\Alive` (**Settings → Data folder**). Больше программа
ничего никуда не пишет, даже в реестр, так что удаление папки сбрасывает её полностью. Только сначала
сохраните `activity.cache` и `notes.cfg`: их не восстановить.

| Файл | Что в нём | Если удалить |
|---|---|---|
| `settings.cfg` | Настройки: папки, колонки, размер и место окна | Всё по умолчанию |
| `index.cache` | Разобранные сеты, чтобы не читать каждый `.als` заново | Соберётся при следующем сканировании |
| `samples.cache` | Библиотека сэмплов | Соберётся заново за минуту-две |
| `activity.cache` | Год работы на главной | **Пропадёт навсегда** |
| `notes.cfg` | Теги и заметки | **Пропадут навсегда** |
| `home.cfg` | Проекты со звёздочкой | Звёздочки пропадут |
| `previews.cfg` | Какой рендер играет у проекта | Снова выбирается сам |
| `nebula.cfg` | Настройки Stat | Всё по умолчанию |
| `thumbs\` | Картинки аранжировок для плиток главной | Нарисуются заново |
| `alive.log` | Что происходило при последнем запуске | Ничего |
| `probes.txt` | Временные копии восстановления, чтобы убрать их после сбоя | Оставшиеся `*.alive-probe.als` останутся на месте |

Хотите держать всё это в другом месте, например рядом с переносной копией? Перед запуском задайте
переменную окружения `ALIVE_HOME` с путём к папке.

## Сборка из исходников

IDE не нужна: Alive собирается компилятором C# из .NET Framework 4.x, который уже есть в системе.

```cmd
build.cmd
```

Получится `bin\Alive.exe`.
