# Options.txt: что за опции и откуда они известны

Ресёрч из отдельной программы Ableton Options, которая теперь живёт внутри Alive окном
`Settings → Live's Options.txt` ([src/OptionsDialog.cs](../src/OptionsDialog.cs), каталог
опций — [src/OptionsCatalog.cs](../src/OptionsCatalog.cs)). Про внешний вид тут больше не
про что читать — он теперь общий с остальной программой; всё остальное в силе.

Редактор `Options.txt` для Ableton Live: галочки вместо ручной правки текстового файла.
Все известные опции собраны в одном списке — с описанием, категорией, диапазоном значений
и пометкой, насколько опции можно доверять.

Цель — **Live 12.4.3** (список опций также покрывает Live 11 и помечает то, что удалено).

## Что умеет

- Сам находит все установленные версии Live в `%APPDATA%\Ableton\Live x.x.x\Preferences`
  и переключается между ними; стабильные версии идут выше бет.
- **153 опции** с описанием: включить/выключить галочкой, у числовых и текстовых — поле значения
  с проверкой диапазона (кликаешь по полю и правишь на месте), у Choice — меню.
- Поиск по названию, описанию и имени опции + фильтр по категории.
- Строка опции (`-_PluginAutoPopulateThreshold=64`) показывается под списком — видно,
  что именно уедет в файл.
- Перед записью автоматически делается резервная копия `Options.txt.bak-ГГГГММДД-ЧЧММСС`.
- Опции, которых нет в каталоге (свои, из будущих версий Live), **не теряются** — читаются из
  файла и сохраняются обратно как есть.
- Если не выбрано ничего, файл удаляется — Live запускается в чистом состоянии.

Изменения вступают в силу только после перезапуска Live.

## Пометки надёжности

Ableton официально документирует лишь несколько опций — остальное держится на знаниях
сообщества и может исчезнуть в любом обновлении. Поэтому у каждой опции стоит бейдж:

| Бейдж | Что значит |
|---|---|
| `официально` | описано в базе знаний Ableton |
| `Live 12` | добавлено/подтверждено в Live 12 |
| *(без бейджа)* | рабочая опция Live 11/12 по данным сообщества |
| `служебная` | внутренняя, для отладки и тестов Ableton — обычному пользователю не нужна |
| `не работает` | удалена в Live 11, в Live 12 не действует (показывается по галочке «Устаревшие») |

Служебные и устаревшие по умолчанию скрыты — включаются галочками в шапке.

Проверено: имена опций **не лежат строками внутри `Ableton Live 12 Suite.exe`** и вообще
нигде в установке Live (Ableton хеширует их при компиляции), поэтому автоматически вытащить
полный список из бинарника нельзя. Каталог собран из официальной статьи Ableton и сверенных
публичных списков, а затем проверен на живом Live 12.4.3.

## Сверка с самим Live

Ключевое наблюдение: **Live сам сообщает, какие опции он не понимает.** При запуске он
разбирает `Options.txt` на первой секунде и на каждое незнакомое имя пишет в
`Preferences\Log.txt`:

```
info: Message Box: The options file [Options.txt] contains an unknown option
'-MidiClockSlave' which will be ignored.
```

Приложение читает этот журнал и помечает такие опции красным бейджем «твой Live её не
понимает», а при сохранении отдельно предупреждает о них. Это точнее любого списка из
интернета и работает для любой версии Live — каталог сам себя проверяет на твоей машине.

Важная тонкость: строки `Options: -X` в том же логе — это **эхо файла**, они пишутся и для
принятых, и для отвергнутых опций. Доверять можно только сообщениям об ошибке.

Что дала проверка на Live 12.4.3:

| Результат | Опции |
|---|---|
| **77 подтверждены** — приняты без единого предупреждения | весь пользовательский набор: `-ShowDeviceSlots`, `-EnableArmOnSelection`, `-NoAutoArming`, `-RestrictAudioCalculationToPerformanceCores`, `-_Feature.Browser.AsyncLoading` и т.д. |
| **9 отвергнуты** — удалены из каталога либо помечены | `-VstNoLocalDir`, `-VstNoScanSkip`, `-NoVstStartupScan`, `-NoMidiMonitorLatencyCompensation`, `-MidiClockSlave`, `-ShowBackToArrangementOnMasterTrack`, `-ThinningAggressiveness`, `-EnableMapToSiblings`, `-ShowToolsMenu` |
| **не проверены** | остальные устаревшие и служебные — они по умолчанию скрыты, и в каталоге честно помечены, а не выданы за рабочие |

Первые восемь до сих пор числятся рабочими во всех публичных списках, включая те, что указаны
в источниках ниже, — эти списки составлялись для Live 11 и устарели.

## Структура

```
src/OptionsCatalog.cs  каталог опций: имя, тип, диапазон, категория, описание (EN + RU)
src/OptionsFile.cs     поиск папок Live, чтение/запись Options.txt, резервные копии
src/OptionsLiveLog.cs  сверка каталога с журналом самого Live
src/OptionsDialog.cs   окно и список опций — на оснастке Alive (GlassDialog, Theme)
src/OptionsLoc.cs      EN/RU в каталоге; интерфейс Alive английский, так что Ru=false
```

Чего в переносе не стало: предпросмотра итогового файла и правки своих опций руками.
Сами опции при этом **не теряются** — неизвестные каталогу строки читаются из файла и
пишутся обратно как есть (`OptionsDoc.Custom`), просто редактировать их негде.

## Как добавить опцию

Одна строка в конце `OptionsCatalog.cs` — заголовок и описание сразу на двух языках:

```csharp
A("ИмяОпции", Kind.Flag, Stat.Ok, CatWorkflow,
  "Short title", "Короткий заголовок",
  "What it does and why you'd want it.", "Что она делает и зачем нужна.");
```

`Kind` — `Flag` / `Num` / `Text` / `Choice`; для `Num` можно задать `def`, `min`, `max`,
для `Choice` — `choices: "a|b|c"`.
